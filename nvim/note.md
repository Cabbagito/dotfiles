## Neovim Git Plugins

### [Diffview.nvim](https://github.com/sindrets/diffview.nvim)
- **What is it?**  
  A single tabpage interface for easily cycling through diffs for all modified files for any git revision. It provides a way to visually review all changed files for any git commit, branch, or tag in a convenient, unified UI.
- **Key Features:**  
  - Review diffs of all modified files at once
  - Visual file and directory history
  - Powerful merge conflict resolution using 3-way and 4-way diff layouts
  - Stage, unstage, and restore changes from the interface
  - Compatible with Neovim’s diff mode for more advanced workflows

***

### [Neogit](https://github.com/NeogitOrg/neogit)
- **What is it?**  
  An interactive and powerful Git interface for Neovim, inspired by Magit. It’s a comprehensive git plugin for Neovim that allows you to interact with git repositories directly within the editor.
- **Key Features:**  
  - Visual Git status buffer
  - Interactive popups for common Git actions (commit, push, pull, merge, etc)
  - Branch and stash management
  - Log, diff, and rebase tools
  - Deep integration with other Neovim plugins like Diffview for advanced diff/merge workflows
